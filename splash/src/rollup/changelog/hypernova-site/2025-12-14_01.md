# Changelog - 2025-12-14 (#1)

## Hypernova Site: Slides System Implementation — Auto-Discovery, Theme Integration, and Image Assets

### Overview

This sprint delivered a comprehensive **RevealJS slides system** for the Hypernova site with three major capabilities:

1. **Auto-Discovery** — Presentations are automatically discovered from three sources: component decks, standalone `.astro` pages, and markdown files.
2. **Theme/Mode Integration** — Slides properly inherit the Hypernova theme and respond to dark/light mode switching.
3. **Image Assets** — Consistent `coverImage`/`shareImage` properties with intelligent fallbacks across all presentation types.

**Key Achievement:** A unified presentation system that supports both highly-designed component decks and quick markdown-based presentations, all with proper theming.

---

## Architecture

```
src/pages/slides/
├── index.astro          ← Auto-discovers all presentations
├── [...slug].astro      ← Dynamic routing for all deck types
├── Global-CVC-for-Multinationals.astro  ← Standalone presentation
└── The-Future-of-CPG.astro              ← Standalone presentation

src/data/
├── componentDecks.ts    ← Registry for component-based decks
└── markdownDecks.ts     ← Loader for markdown content collection

src/layouts/
├── OneSlideDeck.astro       ← RevealJS wrapper with theme integration
└── MarkdownSlideDeck.astro  ← Markdown-to-slides converter

src/content/slides/
└── *.md                 ← Markdown presentations (slide separator: ---)
```

### Presentation Discovery Flow

```
slides/index.astro
       │
       ├─► componentDecks.ts ──► Component Decks (hypernova-strategy)
       │
       ├─► import.meta.glob('./*.astro') ──► Standalone Pages
       │
       └─► markdownDecks.ts ──► Markdown Decks (institutional-grade, etc.)
       │
       ▼
Unified Presentation[] ──► TitleSlidePreviewCard ──► Grid Display
```

export interface ComponentDeck {
  title: string;

export const componentDecks: Record<string, ComponentDeck> = {
  'hypernova-strategy': {

**Helper functions:**
- `getComponentDeck(slug)` — Get a single deck by slug
- `getAllComponentDecks()` — Get all decks as array with slugs

### 2. Markdown Deck Auto-Loading

**New: `src/data/markdownDecks.ts`**

Dynamically loads markdown presentations from the `slides` content collection:

```typescript
interface MarkdownDeckData {
  title: string;
  description: string;
  component: string;
  content?: string;
  coverImage?: string;
  shareImage?: string;
}

// Loads all markdown files from src/content/slides/*.md
const loadMarkdownDecks = async () => {
  const slides = await getCollection('slides');
  for (const slide of slides) {
    markdownDecks[slug] = {
      title: slide.data.title,
      description: slide.data.description,
      coverImage: slide.data.coverImage,
      shareImage: slide.data.shareImage,
      content: slide.body
    };
  }
};
```

### 3. Auto-Discovery in Index Page

**Modified: `src/pages/slides/index.astro`**

Unified presentation interface combining all three sources:

```typescript
interface Presentation {
  title: string;
  slug: string;
  description: string;
  date?: string;
  author?: string;
  tags?: string[];
  icon?: string;
  coverImage?: string;  // For card display
  shareImage?: string;  // For OpenGraph
  type: 'component' | 'standalone' | 'markdown';
}
```

**Discovery sources:**
1. Component decks from `componentDecks.ts` registry
2. Standalone `.astro` pages via `import.meta.glob('./*.astro')` with lazy loading
3. Markdown decks from `markdownDecks.ts`

**Key fix:** Changed from `eager: true` to lazy loading to prevent OneSlideDeck's CSS from leaking into the index page.

### 4. Theme/Mode Integration

**Modified: `src/layouts/OneSlideDeck.astro`**

Fixed theming to use Hypernova theme with proper dark mode:

```astro
<!-- Before -->
<html lang="en" data-theme="water">
import '@styles/water-theme.css';

<!-- After -->
<html lang="en" class="theme-hypernova dark" data-theme="hypernova" data-mode="dark">
import '@styles/nova-theme.css';
```

**CSS Variables for slides:**
```css
:root {
  --slide-bg-primary: rgb(var(--color-primary-950));
  --slide-text-primary: rgb(var(--color-primary-50));
  --slide-text-secondary: rgb(var(--color-primary-100));
  --slide-accent: rgb(var(--color-accent-500));
  --slide-accent-bright: rgb(var(--color-accent-300));
}
```

### 5. MarkdownSlideDeck Rewrite

**Modified: `src/layouts/MarkdownSlideDeck.astro`**

Complete rewrite to fix broken nested HTML structure:

**Before:** Created its own `<!DOCTYPE html>` and nested `BaseThemeLayout` inside, causing theme conflicts.

**After:** Simply wraps content in `OneSlideDeck`:

```astro
<OneSlideDeck title={title} description={description}>
  <Fragment set:html={slidesHtml} />
</OneSlideDeck>

<style is:global>
  .slide h1 { color: var(--slide-text-primary); }
  .slide h2 { color: var(--slide-text-primary); }
  .slide p { color: var(--slide-text-secondary); }
  .slide strong { color: var(--slide-accent-bright); }
</style>
```

### 6. Mode-Responsive Preview Cards

**Modified: `src/components/slides/TitleSlidePreviewCard.astro`**

Refactored CSS to respond to dark/light mode:

```css
/* Light mode defaults */
.presentation-card {
  background: var(--color-card);
  border: 1px solid var(--color-border);
}

/* Dark mode overrides */
:global(html[data-mode="dark"]) .presentation-card,
:global(html.dark) .presentation-card {
  background: rgba(255, 255, 255, 0.05);
  border-color: rgba(255, 255, 255, 0.1);
}
```

### 7. Image Asset Fallback System

**Image property cascade:**

```typescript
// Card display: coverImage → shareImage → site default
const displayImage = coverImage || shareImage || DEFAULT_COVER_IMAGE;

// Share button: shareImage → coverImage → site default
image={shareImage || coverImage || DEFAULT_SHARE_IMAGE}
```

**Default images created:**
```
public/images/slides/
├── default-cover.jpg    # 1600x900 card preview
└── default-share.jpg    # 1200x630 OpenGraph
```
