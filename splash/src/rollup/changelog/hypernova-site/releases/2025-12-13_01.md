# Hypernova Capital Website — Release v0.1.0

**Release Date:** December 13, 2025
**Version:** 0.1.0
**Status:** Production-Ready

---

## Executive Summary

Hypernova Capital's website is a comprehensive, production-grade Astro application featuring enterprise-level portfolio management, confidential content delivery with multi-tier authentication, and a modern design system with 35+ reusable components.

This release consolidates all features developed through December 2025, including the newly implemented confidential content access control system with GitHub-integrated memo delivery.

---

## Key Features

### 1. Confidential Content Access Control (NEW)

A complete authentication system protecting sensitive portfolio information and investment memos.

**Components:**
- **Passcode Gate** (`/portfolio-gate`) — Universal passcode entry with redirect preservation
- **Middleware Protection** — Server-side route protection for `/portfolio/confidential` and `/memos/*`
- **Session Management** — Secure httpOnly cookies with 24-hour duration
- **Flexible Validation** — Supports both plaintext (dev) and SHA256 hashed (production) passcodes

**Protected Areas:**
- `/portfolio/confidential` — Enhanced portfolio view with LP commitments and direct investments
- `/memos/[slug]` — Investment memo viewer with PDF export

### 2. GitHub-Integrated Memo System (NEW)

Confidential investment memos fetched at runtime from a private GitHub repository.

**Features:**
- **Runtime Fetching** — Content never exists in static build assets
- **Slug-to-Path Derivation** — Automatic conversion of URL-safe slugs to GitHub file paths
- **5-Minute Caching** — In-memory cache to reduce API calls
- **Local Fallback Mode** — Development works without GitHub PAT using local markdown files
- **Frontmatter Parsing** — Automatic YAML frontmatter extraction

**Current Memos (18 total):**

- Handle, Harmonic, Kearny Jackson, Maven Clinic, Ontra, Star Catcher

## Architecture

### Rendering Modes

| Route Pattern | Mode | Reason |
|---------------|------|--------|
| `/portfolio` | Static | Public content |
| `/portfolio/[slug]` | Static | Public company pages |
| `/portfolio/confidential` | SSR | Protected content |
| `/memos/[slug]` | SSR | Runtime GitHub fetching |
| `/api/*` | SSR | Backend endpoints |

### Authentication Flow

```
User → /portfolio/confidential
         ↓
    [Middleware Check]
         ↓
    No Cookie? → Redirect to /portfolio-gate
         ↓
    Enter Passcode
         ↓
    POST /api/verify-portfolio-passcode
         ↓
    Validate (plaintext or hash)
         ↓
    Set Cookie (24hr, httpOnly, secure, strict)
         ↓
    Redirect to Original URL
```

### Content Flow (Memos)

```
/memos/[slug]
     ↓
[Auth Check] → No Cookie? → /portfolio-gate
     ↓
[GitHub PAT configured?]
     ↓
   Yes → fetchGitHubContent()
         → Check cache (5min TTL)
         → Fetch from raw.githubusercontent.com
         → Parse frontmatter
         → Render markdown
     ↓
   No → fetchLocalMemo()
        → Read from src/content/markdown-memos/
        → Show "Local Demo Mode" banner
```

## Security Features

1. **Cookie Security**
   - `httpOnly: true` — Prevents XSS attacks
   - `secure: true` (production) — HTTPS only
   - `sameSite: 'strict'` — Prevents CSRF

2. **Content Security**
   - Confidential memos never in static build
   - GitHub PAT server-side only
   - Fine-grained PAT with minimal permissions

3. **Session Management**
   - 24-hour session duration
   - Cryptographically secure session tokens
   - Redirect preservation for UX

## Known Limitations

1. **Single Passcode** — All users share one passcode (Tier 1 auth)
2. **No Audit Logging** — Access attempts not persisted
3. **No Rate Limiting** — Passcode endpoint unprotected from brute force
4. **PAT Expiration** — Requires manual rotation every 90 days
