# Project Scaffold Summary — cogs-site (Coglets AI)

## Why Care?

Coglets is an AI employee platform — the marketing site is what puts that pitch in front of prospects. cogs-site is built to be fast, zero-JS by default, and fully on-brand, with Astro 5's server-first architecture doing the heavy lifting so the page loads before the user blinks.

This entry initializes the `changelog/` for the repo. The site had no log before this; all prior progress lives only in git history. This entry is a retrospective scaffold summary.

## What's New? (as of 2026-07-06)

- **Full marketing section stack** — Hero, TryCoglets, HowItWorks, remaining sections, social icons, Header, and Footer all in place.
- **Coglet brand logo** — corrected and in production (`fix(logo)` commit).
- **Dynamic OpenGraph system** — `src/components/seo/OpenGraph.astro` wired to a per-page JSON mapping at `src/components/data/open-graph-mapping.json`. A dedicated share-banner render page at `/share-banner` generates the OG image content. Pre-built banner: `public/share-banners/shareBanner__Coglets--Simple-AI-Employees.webp`.
- **`@astrojs/node` adapter** referenced via pnpm workspace.
- **Astro 5.15.1 + Tailwind CSS 4.1.16** — current versions.

## Architecture Notes

```
src/
├── components/
│   ├── basics/       # Header, Footer
│   ├── seo/          # OpenGraph.astro
│   └── data/         # open-graph-mapping.json
├── layouts/
│   ├── BaseLayout.astro
│   └── sections/
│       ├── heroes/
│       └── try/
└── pages/
    ├── index.astro
    └── share-banner.astro
```

Zero JavaScript by default — CSS-only animations, no client-side JS bundles. Mobile-first responsive design throughout.
