# Dependency upgrade — Astro 6→7, @astrojs/vercel 10→11, @astrojs/svelte 8→9, Tailwind 4.3.0→4.3.2

## Why Care?

Astro 7 ships Vite 8 and Rolldown as the default bundler — faster builds, faster dev server cold starts. The Vercel and Svelte adapter major bumps align with Astro 7's updated server entrypoint API. Staying on 6.x with 7.x in the wild means accumulating adapter drift.

## What's New?

| Package | Before | After |
|---|---|---|
| `astro` | `^6.3.1` | `^7.0.6` |
| `@astrojs/vercel` | `^10.0.6` | `^11.0.2` |
| `@astrojs/svelte` | `^8.1.0` | `^9.0.1` |
| `@astrojs/sitemap` | `^3.7.2` | `^3.7.3` |
| `@tailwindcss/vite` | `^4.3.0` | `^4.3.2` |
| `tailwindcss` | `^4.3.0` | `^4.3.2` |
| `svelte` | `^5.55.5` | `^5.56.4` |
| `yaml` | `^2.8.4` | `^2.9.0` |

**Build result:** `Complete!` — server output, Vercel adapter, no errors. Pre-existing `Astro.request.headers` warnings on `llms.txt` pages (not a regression).

## What had to be fixed

Nothing — the site's Svelte components are written in Svelte 5 runes syntax, so `@astrojs/svelte` 9's default runes mode required no `legacy.componentApi` shim. The Vercel adapter v11 accepted the existing `astro.config.mjs` without changes.
