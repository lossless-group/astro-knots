# v0.2.0 — The Checkup

## Why Care?

If you attended the July 29 Agentic VC Dojo, you already used this release: you opened the deck on your own screen, typed answers into the slides, watched the room's responses accumulate on the projector, and wrote the dojo's next agenda in a breakout. This release note is the story of the machinery behind that hour — and what it added to the site permanently.

## What's New?

**The deck is the app.** Session decks can now embed the live polling system directly in slides. Same polls, same tallies across three surfaces — deck, session page, and the new mobile view.

**`/polls/checkup` — vote from your phone.** One question per screen, fill it out, swipe, next. Built for the WhatsApp follow-up blast, with a vertical 1080×1620 share card that unfurls properly and a login flow that now returns you to the poll instead of stranding you on `/me`.

**Recipes is no longer empty.** Three founding guides:
- *How To: Getting Unafraid and Setting Up Your Terminal* — Michael's actual Ghostty + Oh My Posh setup, paste-able end to end, with a "skip it: hand this link to Claude Code" fast path.
- *Orientation: Claude Desktop vs Claude Code* — same brain, different bodies; when to reach for which.
- *Capture Breakout Highlights* — a **downloadable Claude Code agent-skill** (`create-html-breakout-highlights`) that live-captures a breakout, clusters it into themes, links every mentioned tool, reconstructs the dialog, and renders an on-brand HTML page. Our DESIGN.md ships inside the zip.

**Quality-of-life across the site:** copy buttons on every code block, seven new tools in the registry, and the site's first `DESIGN.md` design contract.

## Under the Hood

- Astro 7 silently broke the `astro db execute` CLI that all polling ops depended on; `scripts/db-execute.mjs` restores it by calling @astrojs/db's internal CLI directly.
- Live-operability proven mid-session: poll caps lifted and a sixth question added while the meeting ran, zero deploys — config lives in Turso, surfaces read per-request.
- OAuth `?next=` round-trip added to all three providers (relative paths only, cookie-carried, defaults preserved).
- OG image dimensions are now overridable per page (`imageWidth`/`imageHeight`), unlocking non-16:9 share cards.

## Versioning

`0.1.3 → 0.2.0` — a feature release: embedded-poll decks, the mobile poll surface, Recipes content + downloadable skill, and auth round-tripping. No breaking changes; `@astrojs/db`'s upstream deprecation remains the tracked migration risk.
