# Project Scaffold Summary — coglet-shuffle (Pug → Astro Migration Complete)

## Why Care?

Coglet Shuffle started as a Shuffle.dev–exported Pug template — polished visuals, steampunk aesthetic, but stuck in a build toolchain that made ongoing development awkward. The migration to Astro brings it into the same stack as the rest of the Astro Knots family: Astro 5, Tailwind v4, pnpm, deployable anywhere.

This entry initializes the `changelog/` for the repo. Prior progress lives only in the `MIGRATION-STATUS.md` file and git history.

## Architecture Notes

The repo has an unusual two-level structure — the original Pug source is preserved at root, and the active Astro project lives at `astro-site/`:

```
coglet-shuffle/
├── src/           # Original Pug source (reference only — do not edit)
├── public/        # Generated HTML from Pug (reference only)
└── astro-site/    # ← ACTIVE Astro project (work here)
    ├── src/
    │   ├── pages/index.astro
    │   ├── layouts/Layout.astro
    │   └── components/  (12 components)
    └── public/
        └── saturn-assets/
```

**Custom theme:** Orange `#FF460C` palette, steampunk styling, Sora + Playfair Display fonts. Tailwind v4 `@theme` directive — CSS-based config, no JS config file.

**Alpine.js** used only for the mobile navigation dropdown. Everything else is CSS.
