* [Astro Check Type Errors on mpstaton-site](Astro-Check-Type-Errors-on-mpstaton-site.md) - `pnpm build` passes while `astro check` reports 8 errors — five root causes, only one of which lossless-site shares.
* [Documentation Gaps Blocking New Site Onboarding](Documentation-Gaps-Blocking-New-Site-Onboarding.md) - The canonical markdown package has no package.json, and the reference site uses the `workspace:*` pin CLAUDE.md forbids.
* [Hot Reload for Raw-Filesystem Content (across astro-knots sites)](Hot-Reload-for-Raw-Filesystem-Content.md) - `readFileSync` content never hot-reloads — it sits outside Astro's content layer. Needs a Vite watcher AND a dev cache bypass, not either.
* [Images in LFM render without intrinsic dimensions](Images-in-LFM-Render-Without-Intrinsic-Dimensions.md) - Both image paths in the LFM renderer emit an <img> with no width or height, so every image will shift the page as it loads. Latent today because no changelog has images — about to stop being latent.
* [Issue of Saving Stack Edits](Issue-of-Saving-Stack-Edits.md) - Saving stack edits as an authenticated user throws `error:1E08010C:DECODER routines::unsupported` — parked to finish polls first.
* [Nine hand-rolled frontmatter parsers, all functionally identical](Nine-Hand-Rolled-Frontmatter-Parsers-All-Functionally-Identical.md) - One YAML bug had to be fixed nine times. The nine copies turn out to be byte-different and behaviourally identical — the drift is brace style, nothing more.
* [Resolving Mode Switching Across Multiple Components](Resolving-Mode-Switching-Across-Multiple-Components.md) - Astro scopes your `[data-mode]` selector to the component, but the attribute lives on `<html>` — it never matches. `:global()` is the fix.
* [Scripting Across Multiple Tables in NocoDB](Scripting-across-Multiple-Tables-in-NocoDB.md) - Links emailAccess rows to Organizations by email domain, minting orgs as needed — via the `[linkField.id]: [{id}]` update syntax.
* [SSH Key Passphrase Prompts - macOS Keychain Integration](SSH-Key-Passphrase-Prompts.md) - The passphrase prompt returned because `~/.ssh/config` had `UseKeychain` only under `Host gitlab.com` — a `Host *` block fixes the rest.
* [Verifying the Wikilink Resolver Migration on mpstaton-site](Verifying-the-Wikilink-Resolver-Migration-on-mpstaton-site.md) - The migration is written, pushed, and provably identical to the rules it replaces — but nobody has watched it resolve a single real link, because the content it needs is behind two API tokens that only exist on another machine.
* [Workspace vs JSR for LFM Consumers](Workspace-vs-JSR-for-LFM-Consumers.md) - Four sites got flipped to `workspace:*` during the LFM extraction. Only one should be — Vercel never checks out the parent workspace.
