# Specs

* [An Internet-Friendly, Responsive UI for Long-Form Writing](An-Internet-Friendly-Responsive-UI-for-Longform-Writing.md) - A chapter-sequencing reader UI for book-length content — the wrapper owns navigation; LFM keeps every content-level feature.
* [Codifying a Comprehensive Extended Markdown Flavor and Shared Package](Codifying-a-Comprehensive-Extended-Markdown-Flavor-and-Shared-Package.md) - A named, versioned markdown flavor that codifies what we already render, backed by one shared remark/rehype package.
* [Context-V GitHub Fetcher for Multi-Repo Content Aggregation](Context-V-GitHub-Fetcher-for-Multi-Repo-Content-Aggregation.md) - A build-time fetcher that pulls context-v documents from ~20 repos, so lossless.group can render them without copying or submodules.
* [Develop a Slides-only Astro Site for a Fundraise Process](Develop-a-Slides-only-Astro-Site-for-a-Fundraise-Process.md) - A slides-only Astro site that stays consistnent with relevant Context Vigilance files fed into AI Assistant context.
* [Dynamic OpenGraph Images](Dynamic-OpenGraph-Images.md) - Generate an OpenGraph image per page from content and variables, so shares stay on-brand without hand-making an image for every post.
* [Dynamic Portfolio Page Specification and Implementation Plan](Dynamic-Portfolio-Page-Specification-and-Implementation-Plan.md) - Three clickable levels — logo grid, expanding card, detail page — with a passcode gate that reveals placeholders, not real data.
* [Dynamic Webpage to Display Portfolio w Authentication](Dynamic-Webpage-to-Display-Portfolio-w-Authentication.md) - Dynamically display portfolio information on a branded webpage, with certain types of information only displayed for certain privileges connected to authentication.
* [Image Catalog and ImageKit Hosting for Arthouse](Image-Catalog-and-ImageKit-Hosting-for-Arthouse.md) - The repo stays public because it holds metadata only; ImageKit holds the bytes, and a privacy tier keeps NSFW originals out of the output.
* [In The News](In-The-News.md) - Specification for a media coverage section with article display components, sidebar layout, and links to relevant press coverage of portfolio companies.
* [Include Full Search as a Default](Include-Full-Search-as-a-Default.md) - Search ships from the first build via `astro-pagefind`, not at some size threshold. Seven surfaces have it; fifteen do not.
* [Maintain a Multi-Product Changelog with Git Modules](Maintain-a-Dynamic-Multi-Product-Changelog.md) - Each product keeps its own changelog in its own submodule; the org renders them as one feed so progress reads as organization-wide.
* [Maintain a Rigorous Test Suite](Maintain-a-Rigorous-Test-Suite.md) - With AI Code Assistants on the rise, maintaining a rigorous test suite is more important than ever. Maintaining a test suite that catches regressions and ensures the website is performing as expected is a must.
* [Create an Image-Heavy Portfolio Website for Boutique E-Commerce](Maintain-an-Image-Heavy-Portfolio-Site.md) - A mobile-first, image-heavy portfolio site: carousel galleries, tiered pricing cards, WhatsApp CTA, all managed through markdown.
* [Maintain an Interactive `Stack` Display](Maintain-an-Interactive-Stack-Display.md) - A browsable display of the tools a professional uses to work — markdown plus JSON, no database, in the spirit of AI-friendliness.
* [Polish Pass for Arthouse Site](Polish-Pass-for-Arthouse-Site.md) - Takes arthouse-site from scaffold-complete to client-presentable, with an AI photo-to-illustration pipeline for sensitive source material.
* [Portfolio-Wide Job Aggregator](Portfolio-Wide-Job-Aggregator.md) - A specification for scraping, aggregating, and displaying job openings across a venture capital firm's portfolio companies — built as a reusable pattern for any VC client site.
* [A Reading-Position Table of Contents for LFM Articles](Reading-Position-Table-of-Contents-for-LFM-Articles.md) - LFM already hands every renderer a build-time outline; nothing renders it. One component, three viewport-driven states — left rail, hamburger overlay, mobile header — and a scrollspy that always knows which heading you're in.
* [Remark-Citations: A Unified Plugin for Hex-Code Footnote Management](Remark-Citations-Plugin-for-Hex-Code-Footnote-Management.md) - A standalone remark plugin that transforms footnote identifiers (hex codes, numeric, or mixed) into sequentially-numbered citations with structured metadata parsing, designed for the unified/remark ecosystem and bundled into @lossless-group/lfm.
* [Versatile Component Library for Video Players](Versatile-Component-Library-for-Video-Players.md) - Videos links can come from various sources, and include metadata, playlists, and other information that handled to maximize the value of video content, all from simple markdown triggers.
