## Why Care?

Every site wants its own layout, style and markup. If the sites all pulled on
one shared copy of these components, every change would turn into a pull
request war. They're meant to be copied and adapted, and now each file says so.

## What's New?

- **A banner at the top of every component** in `packages/lfm-astro`: copy
  this into your site and adapt it; it isn't a hard dependency.
- **`README.md`**: the copy-and-adapt model and what each file is for.
- **`WHATS-NEW.md`**: dated changes to these components, for sites to pick up
  by hand. It starts with the link fix below, the
  `CrossReferenceContentEmbed` addition (2026-11-17) and the `CodeBlock`
  highlighter (2026-11-09).
- **Links in `.reader` content are styled**: primary color, a thin underline
  that darkens on hover, plain citation markers.

## Under the Hood

- The link fix came from cathode-site, where a global `a { color: inherit }`
  reset made every link in a write-up look like body text. Any site with that
  reset had the same problem.
