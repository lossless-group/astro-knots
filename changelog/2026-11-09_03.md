## Why Care?

Every note and changelog page on the splash showed its title, lede and tags,
then nothing. The splash's content loaders store each entry's raw markdown
but no rendered HTML, so Astro's `render()` built cleanly and returned an
empty page. A splash about Astro Knots wasn't using our own markdown.

## What's New?

- **Bodies render through LFM.** Each page parses its markdown with
  `@lossless-group/lfm` (0.7.0, from JSR, no token needed) and renders it
  with `AstroMarkdown`, so callouts, citations, code blocks, tables and
  images look the way they do on our other sites. Citations get their
  Sources list.
- **The components are the canonical ones**, copied from
  `packages/lfm-astro/components/`; the adapter follows the
  context-vigilance-kit splash.
- **Links between notes work.** `[[Wikilinks]]` and links to `.md` files go
  to the note's page when it's published here, and stay as plain text when
  it isn't.
- **Code blocks in color.** `CodeBlock` calls LFM's own highlighter
  (`@lossless-group/lfm/highlight`, new in 0.7.0), sitting on the page's
  background so the palette reads in light, dark and vibrant, with a language
  label and a copy button. The canonical copy in
  `packages/lfm-astro/components/` got the same change, so every new site
  starts with it.
- **No doubled titles.** The title shown in the page header is dropped from
  the top of the body, even under the rollup's provenance comment.

All 227 note and changelog pages now have a body.
