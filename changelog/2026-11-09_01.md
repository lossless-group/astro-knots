## Why Care?

The patterns behind these sites are now something other people can use. Paste
one prompt into Claude Code or Codex, and the agent installs the Astro Knots
plugin, loads our skills, and checks every edit for React and JSX habits, then
asks what you're building.

## What's New?

- **A "Build a site" section on the splash**, linked from the hero and the
  nav: a copy-a-prompt box, the install commands for Claude Code and Codex,
  and what the guardrails cover. The plugin lives in
  [astro-knots-mcp](https://github.com/lossless-group/astro-knots-mcp). The
  link-MCP step appears once its Worker is deployed.
- **An issue on iPhone share previews.** A page with two `og:image` tags gets
  a preview mixing the tall and wide banners, seen on FantasyGM. The fix:
  exactly one `og:image` per response, tall by default, with an edge layer
  serving each app the card it shows best.
- **The design-system blueprint learned the spike rhythm.** Agents build new
  UI faster and better without the component library in mind, so creative
  work breaks free of it and then gets refactored back into the components
  and onto the theme. New section 7.1, and two new skills behind it.
