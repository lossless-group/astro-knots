# Astro Knots' 111 Docs Become a Bundle Any Agent Can Read

## Why Care?

`astro-knots/context-v/` is where the conventions for a whole family of Astro sites live: how themes and modes work, how markdown renders, how decks, portals, and OG images get built. It's one of the most-read doc sets in the tree, and until today an agent landing here had to open each of its 111 files to learn what kind of doc it was. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle. Any OKF reader can list what's here and what each doc is for without opening a thing.

## What's New?

- **107 docs declare their `type`**, the Train-Case name of the folder they live in: `Blueprints`, `Specs`, `Prompts`, `Reminders`, `Explorations`, `Issues`, `Sitemap`, `Plans`, `Loops`, `Strategy`. The other 4 already had one.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its ten folders.
- **Eight new folder indexes**, one line per doc with its lede. The `explorations/` and `plans/` indexes already existed and stay as they were.
- **The splash skips `index.md`** when loading `context-v/`, its own and every rolled-up child's, so the indexes stay navigation for agents and don't become pages.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, one file at a time. The whole doc diff is 107 added `type:` lines and nothing removed. No dates moved: this is a compliance change, not a content change.
- `context-v/README.md` sits at the bundle root, not in a folder, so it carries no `type`.
- The sites under `sites/` are their own repos and their own bundles; each was swept in its own commit on 2026-10-31.
- The branches were reconciled first: `main` had three commits `master` had already superseded, so `main` was merged into `master` keeping `master`'s tree, and all three tiers moved to one tip.
